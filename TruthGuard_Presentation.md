# TruthGuard Presentation Draft

## Slide 1: Title
**TruthGuard: AI-Based Misinformation Detector**

- A smart project that helps people check whether news or information is trustworthy.
- It uses Artificial Intelligence to analyze content and give a simple verdict.

**Short speaking line:**
"Today I am presenting TruthGuard, a project that helps detect misinformation using AI."

---

## Slide 2: Problem Statement
**Why this project was created**

- Fake news spreads very fast on the internet.
- Many people believe false information without checking.
- People need a simple tool that can help them judge whether something is true, false, or uncertain.

**Short speaking line:**
"In today’s digital world, fake information spreads quickly, so we need tools that can help users verify content."

---

## Slide 3: What is TruthGuard?
**Project idea**

- TruthGuard is a web and mobile-based platform.
- Users can enter a news text or a link.
- The system analyzes it and gives a result such as:
  - Likely Misinformation
  - Questionable / Unverified
  - Likely Factual
  - Satire / Opinion

**Short speaking line:**
"TruthGuard acts like a digital assistant that checks information before people trust it."

---

## Slide 4: Main Features
**What the project does**

- Analyzes text or links
- Gives an AI-based verdict with confidence score
- Shows trending misinformation from fact-checking sources
- Provides a simple and modern user interface
- Supports web and mobile platforms

**Short speaking line:**
"The project combines AI analysis and real-world fact-checking data to offer a useful result to users."

---

## Slide 5: How the System Works
**Simple flow**

1. User enters text or URL
2. Frontend sends the data to backend
3. Backend sends the request to AI models
4. AI analyzes the content
5. Result is shown back to user

**Very simple explanation:**
"The website collects the input, the server processes it, and the AI gives the final decision."

---

## Slide 6: Technologies Used
**Frontend Technologies**

- React.js
  - A JavaScript library used to build the user interface.
  - In simple words, it helps create the pages you see on the website.

- Vite
  - A very fast tool that helps run and build the frontend project.
  - It makes development quicker.

- Tailwind CSS
  - A styling tool used to make the website look attractive.
  - It helps design buttons, layouts, and colors easily.

- Framer Motion
  - A library for animations.
  - It adds smooth movement and visual effects.

- Axios
  - A tool used to send data from the frontend to the backend.
  - It is like a messenger between the web page and the server.

- jsPDF
  - A library used to generate PDF files in the browser.
  - It helps create reports and documents.

---

## Slide 7: Technologies Used
**Backend Technologies**

- Node.js
  - A runtime that allows JavaScript to run on the server.
  - It helps the project handle requests from users.

- Express.js
  - A framework used to build APIs.
  - It helps create routes such as analyzing text and fetching trends.

- Gemini API
  - An AI service from Google that understands and analyzes text.
  - It helps the system decide whether something looks trustworthy or suspicious.

- Google Fact Check Tools API
  - A tool that provides real fact-check information from trusted sources.
  - It helps the system compare the input with verified claims.

- dotenv
  - A package that keeps secret keys safe in environment variables.
  - It protects important credentials.

**Simple explanation:**
"The backend is the brain of the project. It receives requests and uses AI and fact-checking services to produce answers."

---

## Slide 8: Mobile Technology
**Mobile App Tech**

- React Native / Expo
  - Used to build the mobile app version of the project.
  - It allows the app to run on phones using one codebase.

- Expo
  - A platform that makes mobile app development easier.
  - It helps test and run the app smoothly.

**Simple explanation:**
"This means the same project can also work on mobile phones, not just on a browser."

---

## Slide 9: Why This Project is Useful
**Impact and importance**

- Helps people verify information quickly
- Supports better digital awareness
- Combines AI with trusted fact-checking data
- Can be useful for students, journalists, and everyday users

**Short speaking line:**
"This project is important because it helps people become more careful and informed in the age of misinformation."

## Slide 10: Challenges and Future Scope
**What can be improved**

- AI can sometimes make mistakes
- Internet-based fact-checking depends on live data availability
- The system can be improved with better accuracy and multilingual support

**Future ideas:**
- Add support for more languages
- Improve detection accuracy
- Add browser extension or chatbot version

**Short speaking line:**
"Although the project is strong, there is still room to improve accuracy and expand its features."

## Slide 11: Conclusion
**Closing message**

- TruthGuard is a useful project that uses AI to fight misinformation.
- It shows how technology can help society make better decisions.
- It is a simple but meaningful step toward a more trustworthy digital world.

"Thank you."
