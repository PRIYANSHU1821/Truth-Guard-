# TruthGuard Chrome Extension

## Load locally

1. Start the backend: `cd backend && npm start`.
2. In Chrome, open `chrome://extensions` and enable **Developer mode**.
3. Select **Load unpacked** and choose this `chrome-extension` folder.
4. Open the extension settings to set the backend URL when it is not `http://localhost:5000`.

Select text on a page and open TruthGuard to analyze it, or use **Analyze page text**.

## Package

Zip the contents of this folder (not the folder itself) to prepare it for Chrome Web Store upload.
